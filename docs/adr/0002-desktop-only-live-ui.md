# ADR 0002: Desktop как единственный live-интерфейс

- Статус: Accepted.
- Дата: 2026-10-20.
- Связанные материалы: `openspec/changes/archive/2026-10-20-cleanup-dependencies-and-desktop-only-mode/`.

## Контекст

Tauri запускает локальные PostgreSQL, FastAPI и worker, затем подключает React к выданным адресу и токену. Параллельно сохранился браузерный путь разработки: обычный Vite-сервер проксирует `/api` на фиксированный порт FastAPI, а React без desktop-флага отправляет запросы по относительному адресу. Отдельная команда `dev:e2e` поднимает UI с mock API для браузерных Playwright E2E.

## Решение

Оставить Tauri единственным интерфейсом для живых данных. Удалить обычный Vite live-режим, его API proxy и браузерную ветку подключения к живому API. Сохранить `dev:e2e`, mock API и браузерный Playwright E2E как основной набор проверок интерфейса. Сохранить FastAPI, который запускает Tauri и самостоятельная CLI-команда. Небольшой Tauri E2E набор рассматривать отдельно в будущем для IPC и интеграции служб.

## Рассмотренные варианты

1. **Сохранить web-разработку без публичного обещания поддержки.** Меньше изменений, но остаётся второй способ подключения с другим запуском, фиксированным портом и непроверенными desktop-операциями.
2. **Удалить все браузерные режимы, включая E2E-стенд.** Упростило бы дерево режимов, но уничтожило бы существующее быстрое покрытие UI; будущий Tauri E2E не должен дублировать все браузерные сценарии.

## Последствия и ограничения

- Пользователи прежнего Vite + FastAPI интерфейса потеряют этот путь запуска.
- Локальные API-маршруты, worker, самостоятельные CLI-команды и JSON-режим одного Ozon ID сохраняются. Миграции БД и история цен не затрагиваются.
- Браузерный Playwright E2E с mock API остаётся тестовым инструментом и не подтверждает работу живых desktop-служб.
- Проверка desktop-старта и упаковки обязательна после удаления web-веток.

## Решение пользователя

Пользователь утвердил desktop как единственный live-интерфейс и сохранение
браузерного E2E как основного набора проверок UI. Небольшой набор Tauri E2E
можно добавить позже. Реализация принята 2026-10-20.
