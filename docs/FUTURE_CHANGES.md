# Будущие доработки

Здесь фиксируются задачи, обнаруженные при работе приложения. Пункты в этом
файле запланированы, но ещё не реализованы.

## Товары, пропавшие из продажи на Ozon

**Состояние:** отложено по решению пользователя; не входит в ближайшую реализацию.

Когда товар исчезает из продажи, Ozon может перенаправить его страницу на поиск
с предложениями. Так происходит с артикулом `1604900984`: ответ содержит
`pageInfo.pageType = "search"`, но не содержит виджетов карточки
`webProductHeading-` и `webPrice-`. Сейчас коннектор не может извлечь название и
цену, поэтому сбор этой карточки завершается ошибкой.

Ожидаемое поведение:

1. Распознавать достоверное перенаправление исходного артикула на страницу
   предложений как отсутствие товара в продаже.
2. Сохранять для исходной карточки наблюдение с `availability = "out_of_stock"`
   и `price = null`. Оставлять ранее известные название и ссылку карточки.
3. Не подменять исходную карточку и её цену данными предложенных товаров.
4. Если ответ похож на ошибку сети, антибот-проверку или изменение схемы Ozon,
   сохранять текущую обработку ошибки: не записывать ложное отсутствие товара.
5. Добавить тесты для обычной карточки, подтверждённого перенаправления на поиск
   и неоднозначного ответа. Проверить отображение статуса в интерфейсе и
   сохранение истории цен.

Задача считается выполненной, когда пропавший товар отображается как
«Нет в наличии» с пустой текущей ценой, а доступные товары продолжают
собираться без изменений.

## Ускорение сбора нескольких товаров

**Состояние:** отдельное исследование после ближайших исправлений.

Сейчас коннектор открывает товар через Chrome отдельно для каждого артикула.
Последовательный обход и повторное открытие страницы делают общий запуск долгим.
Нужно измерить время на запуск браузера, навигацию, проверку Ozon и получение JSON
для каждого товара, а затем сравнить варианты ускорения: повторное использование
одного браузерного контекста, одной или нескольких вкладок и ограниченный
параллелизм. При выборе решения учитывать общий Chrome-профиль, антибот-проверку,
порядок результатов и ограничения Ozon. До измерений не обещать конкретный
выигрыш или безопасный уровень параллелизма.

Ожидаемый результат исследования: замеры на нескольких карточках, выбранный
вариант с описанием рисков и отдельная спецификация реализации.
