# Нюансы и известные ограничения

[К содержанию](README.md)

## Desktop зависит от каталога проекта

`./price-watch` запускает уже собранный Tauri бинарник из дерева репозитория.
Сам бинарник ищет корневой `.env`, `.venv/bin/python` и `main.py`
рядом с исходниками. Путь можно переопределить переменной
`PRICE_ANALYZER_PROJECT_DIR`. При установке `price-watch-bin` код размещается
в `/usr/lib/price-watch`; AppImage не собирается.
Работа локальных служб описана [отдельно](NATIVE_DESKTOP.md).

Desktop хранит профиль Chrome в `$XDG_DATA_HOME/price-watch/chrome-profile`
(по умолчанию `~/.local/share/price-watch/chrome-profile`), а лог локального
worker — в `$XDG_STATE_HOME/price-watch/desktop-worker.log` (по умолчанию
`~/.local/state/price-watch/desktop-worker.log`). При первом запуске старый
`.playwright-profile` переносится из проекта в каталог данных. Если Chrome
использует старый профиль или оба каталога уже существуют, приложение попросит
закрыть браузер или разрешить конфликт профилей вручную. Корневой `.env` и
данные PostgreSQL находятся в пользовательском каталоге XDG.

## Браузер и режимы

При запуске desktop приложения Chrome не открывается. Кнопка «Открыть Chrome»
запускает системный Google Chrome на X11/XWayland с вкладками Ozon, Wildberries,
AliExpress и Яндекс Маркета. Его профиль хранится в пользовательском каталоге
данных. При нажатии «Обновить» приложение закрывает Chrome, открытый этой
кнопкой, и только затем
запускает сбор. Worker использует тот же профиль, но запускает отдельный Chrome
на скрытом дисплее. Поэтому вход в Ozon, сохранённый в профиле, доступен при
сборе, а окна браузера сбора не появляются на рабочем столе.

Если Chrome не установлен, desktop сбор сообщает об ошибке. Профиль нельзя
одновременно использовать в двух процессах Chrome; перед автоматическим сбором
worker также закрывает открытый Chrome приложения через CDP.

## Данные маркетплейсов

Коннектор реализован только для Ozon. Карточки Wildberries, AliExpress и Яндекс
Маркета можно добавить вручную, но сбор для них отсутствует. Для Ozon цена
берётся строго из `cardPrice`: обычная цена или цена без карты не подставляется
вместо неё.

Если Ozon перенаправил исходный артикул на страницу поиска с предложениями,
сбор сохраняет наблюдение `out_of_stock` с пустой текущей ценой. Прежние
название и ссылка карточки сохраняются; цены предложенных товаров не
подставляются. Неоднозначный ответ по-прежнему считается ошибкой сбора.

Сбой одной карточки не останавливает сбор других. Подробная причина есть в
логах и деталях запуска в интерфейсе. Ошибочные карточки можно повторить
отдельным запуском. Пока worker работает, он проверяет необходимость полного
автоматического сбора раз в минуту; отсчёт составляет 12 часов от последнего
полного запуска. Сбор одной карточки и повтор ошибок срок не сдвигают.
Выгодные предложения доступны через фильтр на странице карточек, а уведомление о
новой выгодной цене показывается в открытом интерфейсе. Отдельной таблицы
попыток пока нет.

## Поведение очереди при аварии

Worker выбирает только строки со статусом `queued`. Если worker аварийно
завершился, при следующем запуске устаревший `running` или `waiting_for_user`
переходит в `failed` с диагностической записью. Автоматического повторного сбора
нет. При обычном закрытии Tauri worker завершается вместе с приложением.
