# Руководство по текущему проекту

Это руководство по текущему коду price-watch. Основной
сценарий — локальное приложение Tauri для одного компьютера. Оно хранит
карточки товаров и историю цен в PostgreSQL и получает данные Ozon, AliExpress.ru и Wildberries через
системный Google Chrome, который worker запускает на скрытом дисплее и
подключает через CDP.

## Что уже реализовано

- Карточки Ozon, конкретных SKU AliExpress.ru и вариантов товара Wildberries, сбор одной карточки или всех карточек.
- История наблюдений, текущая цена и статистика за период.
- API FastAPI, PostgreSQL, Alembic и фоновая очередь сборов.
- React интерфейс для карточек, истории и запусков.
- Desktop оболочка Tauri с локальным Python worker и Chrome, открываемым кнопкой.
- Режим браузерных E2E-тестов интерфейса с mock API без подключения к базе.

Проект не собирает AppImage: команда `desktop:build` создаёт исполняемый файл
Tauri без установочного пакета.
