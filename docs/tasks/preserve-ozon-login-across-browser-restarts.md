# Сохранение авторизации Ozon при перезапуске Chrome

## План

OpenSpec: `archive/2026-10-21-preserve-ozon-login-across-browser-restarts`. Перевести завершение управляемого Chrome в Rust desktop и Python worker на CDP `Browser.close`, проверить освобождение профиля и сохранность тестового cookie. Не менять пользовательский профиль, данные Ozon или БД во время тестов.

## Состояние

- План одобрен пользователем сообщением «давай»; реализация принята сообщением «Окей, хорошо» после показа результатов и обсуждения первого обновления пакета.
- Обновление `price-watch-bin` не содержит пользовательский профиль и не удаляет его. Текущий профиль существует, содержит cookie Ozon и помечен Chrome как `Crashed`.
- Временный профиль показал `Normal` после CDP `Browser.close`, `SessionEnded` после `SIGTERM`; Playwright `browser.close()` только отключил соединение с внешним Chrome.
- Серверное истечение или отзыв сессии Ozon остаётся независимой возможной причиной повторного входа.
- Добавлен общий Python-модуль CDP `Browser.close`; desktop вызывает его для своего Chrome, worker закрывает свой Chrome тем же механизмом. Принудительная остановка остаётся только после таймаута и записывается в журнал.
- На временном Chrome-профиле тестовый cookie сохранился после закрытия и повторного открытия; `profile.exit_type=Normal` подтверждён и для desktop, и для worker.
- Проверки: 87 Python-тестов прошли (21 пропущен по условиям окружения, включая PostgreSQL); 8 Rust unit прошли (3 ignored), отдельный ignored Rust smoke с настоящим Chrome прошёл; `cargo fmt --check`, `git diff --check`, строгая проверка OpenSpec прошли. CLI `collect --help` и числовой режим загружаются. Манифест установленного и локального пакета не содержит пользовательского профиля.
- Реальное обновление пакета и вход в Ozon не проверялись: релизный скрипт требует чистого Git-дерева, а для живой сессии потребовались бы действия с пользовательским профилем.
- После второго одобрения обновлены `docs/guide/CURRENT_NUANCES.md` и `docs/guide/PACKAGING.md`, синхронизированы `browser-profile-lifecycle` и `scheduled-collection`; `openspec validate --specs` прошёл (6 спецификаций). Change архивирован, все 8 задач отмечены выполненными.

## Следующее действие

Для установки новой версии собрать локальный пакет из чистого Git-дерева; саму установку и публикацию не выполнять в рамках этого шага.
