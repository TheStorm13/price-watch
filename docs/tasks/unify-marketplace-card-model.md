# Единый MarketplaceCard и отдельная запись отслеживания

## Состояние

2026-10-25: пользователь выбрал вариант 1: общий MarketplaceCard для товара
всех площадок и отдельная запись TrackedCard для локального отслеживания.
Выбран путь «ответ площадки → её модель → mapper → MarketplaceCard» и Decimal
для цен. Полный план, включая строковое денежное представление JSON, одобрен
пользователем («Хорошо, действуй»). Реализация начата; после прерывания
пользователь попросил продолжить. После отчёта о проверках пользователь
принял реализацию запросом «Сделай коммиты все, чтобы дерево было чистым»
и разрешил включить все предшествующие изменения.
Baseline: /tmp/unify-marketplace-card-model-baseline.patch, baseline-status.txt
и baseline.tar.gz с исходными файлами; это временные материалы сессии.
Исходный CLI terminal confirmation зависал при завершении asyncio executor
в sandbox; простая thread-проверка после снятия sandbox проходит.

## План

Канонический [OpenSpec change](../../openspec/changes/archive/2026-10-25-unify-marketplace-card-model/proposal.md),
[design](../../openspec/changes/archive/2026-10-25-unify-marketplace-card-model/design.md),
[tasks](../../openspec/changes/archive/2026-10-25-unify-marketplace-card-model/tasks.md) и
[проект ADR 0005](../adr/0005-marketplace-card-and-tracking-record.md).

1. Общая модель MarketplaceCard, Decimal и локальный TrackedCard.
2. OzonProductData, parser и OzonMapper с сохранением текущего поведения.
3. Перевод исполнителя и PostgreSQL без новой таблицы и изменения гарантий.
4. Точные денежные JSON-контракты и перенос числового CLI с удалением дубликатов.
5. Frontend, mock API, точное сравнение и миграция localStorage уведомлений.
6. Сквозные проверки, отдельное принятие, документация, specs/archive, коммиты.

ARCH-03 остаётся в backlog. Работы с блокировкой Chrome, восстановлением служб
и прочими именами модулей не входят. Существующая запись именования сохраняется;
её весь прежний объём не считается одобренным или выполненным этим решением.

## Проверки и исходное состояние

Рабочее дерево поверх 9f3876d уже содержало большой набор предшествующих правок,
включая price_analyzer → price_watch. Baseline сохранён до реализации; чужие
изменения не должны попадать в будущие коммиты автоматически.

[Отчёт реализации и проверки](unify-marketplace-card-model/verification.md)
содержит изменённые области, команды, результаты, шесть наборов замеров
каталога и отдельный повтор L. Выполнены Python/PostgreSQL, frontend unit,
TypeScript, mock E2E, Rust, desktop build, реальный native smoke с fake
connector и проверка JSON Schema. Файлы ревизий Alembic не менялись.

CodeGraph по-прежнему отказывает в чтении изменённых файлов. Repowise обновлён,
get_change_risk выполнен; находки рассмотрены по исходникам с учётом того,
что индекс считает уже существовавший перенос пакета новым деревом.
Browser plugin отсутствует; использован существующий Playwright workflow.
Пользовательская БД не использовалась, тестовый PostgreSQL создан в /tmp.

Реализованы и проверены 23/23 задачи. Пользователь разрешил зафиксировать
все текущие изменения. Актуальные руководства обновлены, ADR 0005 принят,
две новые спецификации синхронизированы, change архивирован 2026-10-25.

## Завершение

Все текущие изменения включаются в коммиты по прямому запросу пользователя:
настройки агентов — отдельно, приложение, его именование, тесты и документация —
отдельно. Список и хеши коммитов проверяются через git log; результат чистоты
дерева — через git status --porcelain. Push/merge не запрашивались.
