# Массовый выбор карточек и поиск при создании группы

- Фаза: реализация принята запросом пользователя на коммит; пользовательская документация обновлена, спецификации синхронизированы и проверены; OpenSpec change архивирован.
- OpenSpec: `openspec/changes/archive/2026-10-21-bulk-card-selection-and-group-search/`.
- План: чекбоксы для карточек в табличном списке; сохранение выбора при фильтрации и сворачивании групп; создание группы из выбранных или добавление в существующую; массовое включение/исключение из выгодных предложений и удаление; поиск и сортировка по названию в диалоге группы.
- Уточнение пользователя: добавить массовое удаление и возможность добавить выбранные карточки в уже существующую группу. Массовое обновление цен не запрошено.
- Контракты и данные: действующие `POST /api/groups`, `PUT /api/groups/{id}`, `PATCH /api/cards/{id}`, `DELETE /api/cards/{id}`; без миграции и новых API. При добавлении к группе её прежние участники сохраняются, карточка из другой группы переносится без потери истории. Массовое удаление после отдельного подтверждения каскадно удаляет историю. Массовые запросы не атомарны, ошибки показываются отдельно.
- Одобрение: пользователь явно разрешил реализацию после перечисления пяти массовых действий.
- Изменения: `CardsPage` и `useCardSelection` управляют выбором строк; `BulkCardActions` добавляет существующую группу, меняет участие и удаляет с подтверждением и частичным результатом; `GroupDialog` ищет и сортирует карточки; обновлены стили и E2E.
- Проверки: `npm --prefix frontend run lint`, `npm --prefix frontend test` (20 тестов), `npm --prefix frontend run test:e2e` (28 тестов), `npm --prefix frontend run build:desktop`, `openspec validate bulk-card-selection-and-group-search --strict` и `git diff --check` прошли. После выделения хука и последних правок целевые E2E повторно прошли. На снимках 1024 и 1536 px проверена панель действий и отсутствие прокрутки всей страницы по горизонтали.
- Ограничения: E2E используют mock API; живые desktop/API/worker-службы не проверялись. `TEST_DATABASE_URL` отсутствует, поэтому PostgreSQL integration test не запускался. Repowise оценил текущий diff, но обновление его индекса рабочего дерева зависло и было остановлено; графовые сигналы могут быть устаревшими. По текущему коду подтверждено каскадное удаление истории и запрет удаления карточки в активном сборе.
- Завершение: пользователь попросил сделать коммит. Обновлён `docs/UI_SPECIFICATION.md`; спецификации `card-list-selection` и `group-member-selection` синхронизированы с основными и прошли `openspec validate --specs`.
