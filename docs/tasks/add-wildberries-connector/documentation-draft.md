# Документация для второго review

Артефакт второго review. После явной приёмки содержание перенесено в
[руководство Wildberries](../../guide/WILDBERRIES.md) и затронутые руководства.
В опубликованном тексте используется уточнённый термин «вариант товара».

## Руководство Wildberries

Одна карточка отслеживает один выбранный размер. В форме выберите Wildberries,
вставьте полную ссылку с единственным `size` или укажите артикул и код размера.
Например: `https://www.wildberries.ru/catalog/179224846/detail.aspx?size=296499716`.
Идентификатор API/CLI — `179224846:296499716`. Другой размер создаётся отдельной
карточкой. Ссылка должна совпадать с сохранёнными артикулом и размером.

Везде показывается и хранится одна цена: с WB Кошельком, а при подтверждённой
неприменимости кошелька — без него. Процент, округление и лимиты рассчитывает
текущая витрина в профиле Chrome приложения. При ошибке загрузки условий обычная
цена не записывается. Цена соседнего размера или сторонней банковской карты
не заменяет выбранную. Нет остатка выбранного размера — price=null.

WB использует общий Chrome с Ozon/AliExpress и отдельную общую вкладку площадки.
Не нужно открывать каждую товарную страницу. Учитывается регион профиля.
При ручной проверке следуйте сообщению приложения; в скрытом режиме сначала
откройте Chrome приложения, пройдите проверку WB и повторите сбор.

Подтверждённые поля: название, продавец, рейтинг отзывов и их число, размеры,
наличие, цена, цвет из доступной компактной static-записи. Полное описание,
изображения и остальные характеристики могут оставаться пустыми.

## Перенос существующих карточек

Миграция `0016_wildberries_size` меняет numeric WB ID только по однозначному
`size` в соответствующей сохранённой ссылке. Сохраняются локальный ID, история
и её JSON, группы, теги, настройки карточки и цели запусков. Рабочая БД в ходе
разработки не открывалась и не мигрировалась.

Если размеры при переносе создают дубликат, preflight останавливает миграцию
до UPDATE. Активный сбор нужно завершить перед миграцией. Неопределённые
старые карточки сохраняются без изменений; сбор сообщает «Не указан размер WB»
для этой цели. Добавьте выбранный размер новой карточкой. Старую историю можно
сохранить; удаление карточки удаляет её историю. Старый numeric-only импорт
отклоняется, экспорт старой истории доступен.
