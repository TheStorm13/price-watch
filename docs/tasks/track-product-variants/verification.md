# Проверка товара с вариантами

Реализация ожидает отдельной приёмки пользователя; документация guides, sync/archive и Git-коммит выполняются после неё.

## Изменения

- Товарный уровень marketplace_cards, нормализованные card_variants, выбор главного и независимые наблюдения/цели.
- Forward-only миграция 0018 с preflight и сохранением старых ID/снимков/истории.
- Обычный сбор автоматически обнаруживает WB/Ali SKU внутри выбранных товаров; точная цена каждого запрашивается отдельно с действующими правилами площадки. Сессия и предел параллелизма переиспользуются. Цели discovery пакетируются, retry исключает успехи.
- Каталог/группы/выгодные используют главного; карточка и каталог показывают время его успешного сбора. Исторические payload не загружаются для ценовых проекций.
- API вариантов, вариантный фильтр истории, transfer v3, согласованный CLI add/list.
- Общая панель редактирования, поиск/выбор главного, цветные серии, видимость линий и отдельный фильтр измерений. Старая встроенная форма тегов и график единственной серии удалены.

## Инструменты и ограничения

CodeGraph использован с явным корнем проекта. Repowise MCP настроен на старый путь; применены локальные index-only/working-tree update и risk/change-risk. Индекс не даёт полной git-истории новых путей; статические рекомендации не считаются доказательством runtime-корректности.

Browser plugin недоступен в списке инструментов; использован существующий Playwright workflow проекта с DOM-проверками, взаимодействием, pageerror и скриншотами. Визуальные эталоны групп также отражают текущие измеренные высоты виртуализированных строк; просмотрены actual/expected/diff, текст и действия сохранены.

Проверки маркетплейсов детерминированные с фикстурами/синтетическими ответами; текущие живые цены не проверялись. Миграция на пользовательской БД не применялась. Новая схема transfer v3 заменяет v2; старые файлы отклоняются явно. При миграции конфликтующие общие настройки карточек одного артикула останавливают переход до отдельного решения; история молча не удаляется. Рабочие данные не использованы.
