# Редактирование полей карточки

Дата: 2026-11-02. Workflow: vibe-flow. OpenSpec: edit-card-fields.

## Запрос и план

Кнопка «Изменить» в деталях открывает заполненную боковую панель по образцу создания. Редактируются название, URL и до двух тегов. Маркетплейс, артикул, SKU AliExpress и размер WB фиксированы. Общая форма заменяет отдельный редактор тегов. Сохранение через существующий PATCH; отмена отбрасывает черновик; ошибка позволяет повторить без потери ввода. История и другие настройки сохраняются. Миграции не нужны.

## Согласование и состояние

- Исходный план был согласован командой «Приступай к реализации» после уточнения о редактируемых SKU WB и AliExpress.
- Начата незавершённая правка AddCardDrawer.tsx; последнее lint выявило ошибку типизации обработчика автофокуса, исправление было прервано. Тесты не подтверждены.
- Затем пользователь существенно расширил задачу до хранения и сбора всех вариантов с главным SKU и многосерийным графиком. Старый план больше не соответствует запросу; реализация остановлена для пересмотра архитектуры.
- Приёмка реализации ещё не запрошена.

## Проверки

- Изучены AddCardDrawer, CardDetailsPage, useUpdateCard, CardUpdate, PATCH cards и CardRepository.update_card.
- CodeGraph использован с явным путём текущего проекта.
- Repowise MCP указывает старый путь article_json_parser и сообщает устаревший индекс. Запущены локальные repowise update --index-only --no-agents --no-workspace и risk по двум затрагиваемым frontend-файлам; статус команд проверить перед реализацией. Не считать старый MCP-анализ актуальным.
- Тесты приложения до согласования плана не запускались.

## Следующее действие

Получить одобрение новой архитектуры и оформить отдельный change `track-product-variants`; старые artifacts edit-card-fields пока сохранены без переписывания. После реализации необходима отдельная приёмка.
