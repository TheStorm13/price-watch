# Ozon: JSON-запросы из общей браузерной сессии

## План

OpenSpec: `openspec/changes/archive/2026-10-26-ozon-session-json-transport`; ADR 0006 одобрен для реализации.
Заменить открытие вкладки каждого товара общим storefront page и асинхронными fetch JSON-ручки внутри существующего Chrome. Сохранить параллелизм **5 по умолчанию** для реально выполняющихся запросов без скрытой сериализации. Независимый частотный лимит первоначально 5 стартов/секунду с burst 5; Retry-After — общий cooldown, восстановление — одна согласованная операция после завершения активных запросов, отмена — отдельно для каждого fetch. Сохранить MarketplaceCard/Decimal/cardPrice/raw/регион/профиль/историю. Ошибки не превращать в отсутствие товара. Изменения БД/публичных интерфейсов не планируются.

## Реализация и проверка 2026-10-26

- `json_transport.py`: одна owned storefront page, lazy single-flight bootstrap, до 5 настоящих параллельных fetch, 5 стартов/сек с burst 5, независимые AbortController и таймеры. GET с полностью закодированным `/product/{sku}/` и credentials include. При закрытии отменяются собственные запросы и закрывается общая страница.
- `async_client.py`: прежний Chrome/CDP lifecycle, один ref-counted сеанс для конкурентных standalone-вызовов, переиспользование explicit collection_session. Карточки не открываются. Challenge указывает общую вкладку; cookies/регион не сбрасываются.
- HTTP/content/JSON/widgets/identity проверяются и в raw/validate=False. Оригинальный успешный текст возвращается без сериализации. Parser/mapper/Decimal/cardPrice и модель не изменены. Подтверждённый parser-ом removed-product composer остаётся допустимым raw; connector по прежнему правилу выдаёт ProductNotFound.
- До 3 HTTP-попыток. Общий Retry-After (секунды/HTTP-date), длинная пауза -> RateLimited без ранней отправки. Одно восстановление после drain; повторный access failure блокирует последующие отправки этого сеанса. Успешные соседние результаты не отбрасываются.
- Эксперимент `parallel_ozon.py` переведён на тот же connector и session; удалены дублировавшие старый транспорт/процесс ветки; default concurrency 5.
- Новые synthetic тесты: перекрытие 5 fetch/ожидание шестого, точный raw и URL, shared bootstrap, отмена fetch/backoff/bootstrap/recovery wait, общий cooldown и его продление, limited retry/access refresh, schema/HTTP ошибки. CollectionService проверен на отсутствие save_result при MarketplaceUnavailable/SchemaChanged/RateLimited.
- Настоящий Chrome с временным профилем и перехваченными synthetic routes проверяет реальный FETCH_SCRIPT, credentials/cookie, пять одновременных запросов, отдельный abort, таймаут и очистку registry. Два существующих Chrome lifecycle теста подтверждают штатное закрытие и сохранение synthetic cookie после restart. Ozon/пользовательский профиль в этих тестах не используются.
- Полный Python suite после дополнительных проверок: **136 тестов, 96 прошли, 40 skipped**. Пропуски требуют TEST_DATABASE_URL, она не задана. Рабочая БД не открывалась. Изначальная попытка browser-тестов внутри sandbox завершилась PermissionError сокетов/Chrome exit; повтор вне sandbox — все 4 browser/profile проверки прошли. Предыдущий focused запуск прерван на terminal test в sandbox; окончательный full run вне sandbox прошёл.
- `compileall` для marketplace_connector/experiments, `experiments.parallel_ozon --help`, `git diff --check`, strict OpenSpec validate прошли. Frontend/Rust не менялись; demo E2E не запускался и не считается проверкой Ozon.

### Live и сравнение с прежним транспортом

Профиль price-watch, 5 SKU: 1604900984, 1634943359, 1607687714, 1641499399, 1607686851. Новый путь: 0.809 с, **network fetch peak 5**, 5 product GET, 1 home navigation, 0 product navigations. Все 5 вернули текущий полный контракт (5 attributes, 13 variants, seller/rating/image); SKU 1634943359 — 604.00/in_stock.

Прежняя реализация из Git HEAD загружена только во временный measurement-процесс `/tmp`, в приложение не возвращена: при тех же 5 параллельных SKU 2.971 с, 5 product navigations/5 GET, peak 5. Посторонний migrate-ui-to-shadcn не затрагивался.
