# Проверка изображений и данных вариантов

## Источники и принятое правило

Пользователь согласовал: карточка представляет главный вариант со всеми его
данными; группа, теги и участие в выгодных общие. Реализация разрешена явно.
`product_title` хранит название карточки варианта, `title` — подпись варианта
из источника (для списка вместе с `options`).

WB: 2026-11-03 проверена текущая витрина в системном Chrome на временной копии
профиля. Новый пустой профиль получал блокировку. Оригинальный профиль и рабочая
БД не изменялись. Наблюдаемые helpers: `wb.helpers.url.urlProductStatic(nmId)`
использует текущий `constructHostV2`; `wb.helpers.getCardImgName({nmId,viewFlags,idx:1})`
выбирает первый снимок с учётом AB-группы. Текущий image builder витрины использует
тот же host и путь `/images/<size>/<name>.webp`. Код не содержит таблицы basket-хостов.
Производственный runtime проверен через коннектор для `179224846:296499716`:
`https://basket-12.wbbasket.ru/vol1792/part179224/179224846/images/big/1.webp`
вернул HTTP 200, `image/webp`. Это не доказательство доступности всех артикулов WB.

AliExpress: существующая fixture `product-data.json` содержит `imageMainUrl` и
`imagePreviewUrl` у значений `skuInfo.propertyList`; соответствие комбинации
определяется её `skuPropIds`. Тест проверяет точный вариант и переход к общей
галерее при отсутствии его собственного фото. Ozon fixture содержит `data.coverImage`.

## Проверки

- Контракт и мапперы: изображения независимых вариантов и null, сериализация,
  точная комбинация AliExpress и coverImage Ozon.
- WB: 20 browser/transport тестов прошли в системном Chrome с временными профилями
  и синтетической сетью; фото, пустые pics и ошибка необязательного helper покрыты.
- PostgreSQL запускается отдельным временным кластером в `/tmp/pw-variant-db`,
  порт 55439, база `price_watch_variant_utf8_test`. Рабочая БД не использовалась.
- Финальный frontend unit-набор: 21 файл, 86 тестов прошли; TypeScript lint прошёл.
- Полный Python-набор с TEST_DATABASE_URL: 244 теста прошли. После уточнения
  переноса названия при discovery и восстановления прежнего фото из истории:
  ещё 40 релевантных backend-тестов прошли; отдельные 12 тестов вариантов прошли.
- Без DATABASE_URL оба CLI импортируются; числовой Ozon-режим проверен
  существующим тестом с синтетическим коннектором. Direct collect и queued worker
  проверены интеграционным тестом внутри полного Python-набора.
- Финальный desktop release build прошёл после правки графика.
- Изолированный native smoke прошёл: повтор сохранил цену в настоящем WebView,
  перезапуск дочернего API восстановил каталог. Использованы отдельные XDG,
  PostgreSQL и fake connector; это не проверка реального маркетплейса.
- Seed обоих изменённых benchmark-скриптов проверен на временном кластере: экспорт
  двух карточек и создание десяти карточек каталога успешны.
- Первый полный E2E прогон: 54 passed, 7 failed на устаревших селекторах «SKU»
  и ожиданиях ручного ввода размера. После обновления тестов focused: 11 passed,
  один старый WB-сценарий заменён на добавление товара с автоматическим поиском
  вариантов. Финальный полный прогон: **61 passed (4.0m)**.
- Новая browser-проверка охватывает разные миниатюры, переключение названия,
  ссылки, цены, параметров и заглушку при HTTP 404; окна 1440/1024 без overflow.
  Browser pageerror отсутствуют. Предсуществующий React Router HydrateFallback
  warning не относится к этой правке; синтетический HTTP 404 фото ожидаем.
- Screenshot: `/tmp/pw-variant-images-1024.png` (синтетические данные), просмотрен.
- `openspec validate fix-product-variant-images --strict` и `git diff --check` прошли.

## Изменённые области и ограничения

Изменены модели/сериализация и мапперы WB/Ali/Ozon; runtime WB; PostgreSQL
модели, миграция 0019, сохранение/чтение/transfer; API schemas; React карточка,
миниатюра, варианты, график и форма; demo API; затронутые тесты, benchmark seeds
и документация данных/архитектуры. Зависимости и Rust-код не менялись.

Рабочая БД не мигрировалась в ходе проверки. Для оценки нужно перезапустить
приложение, завершив активный сбор, затем повторить сбор WB. Неизвестные фото
вариантов заполняются сбором. Изображения зависят от текущей витрины и CDN.
OpenSpec остаётся открытым до явной пользовательской приёмки; push/merge не выполнялись.

## Инструменты

CodeGraph возвращал текущий исходный код. Repowise MCP вернул устаревший индекс
другого расположения (нет актуальных метаданных целевых файлов); риск проверяется
по текущим исходникам и тестам, локальный индекс обновлён CLI без генерации LLM. Локальный `repowise risk`
проверен отдельно; его score измеряет размер/распределение diff, а не вероятность
ошибки. Критичные paths проверены исходниками и интеграционными тестами.
UI проверяется Playwright проекта: Browser plugin не доступен в этой сессии.
