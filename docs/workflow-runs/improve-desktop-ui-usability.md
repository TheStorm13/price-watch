# Аудит UI и план исправлений

Дата: 2026-10-29. Change: `openspec/changes/improve-desktop-ui-usability`.
Стадия: аудит и предложение. Одобрения реализации и приёмки результата ещё нет.
Пользователь вызвал vibe-flow с просьбой изучить UI и предложить исправления;
после обсуждения Browser/testing попросил продолжить. Это продолжение аудита.

## Среда и границы

- Chromium через установленный Playwright, `http://127.0.0.1:5175`, mock API.
- Проверены 1440×900 и 1024×768, панель также при 1024×700. Проверки 1920×1080 включены в план реализации, в аудите не выполнялись.
- Нет Browser skill/plugin, ожидаемого frontend-testing-debugging; использован его Playwright fallback. Другой инструмент CUA доступен, но не использовался.
- В формах дождались завершения анимаций; ранние снимки `add.png`/`group.png` попали на переход и не используются как доказательство дефекта прозрачности.
- Пользовательская база, реальные маркетплейсы, Rust-команды и native WebView не запускались. Изменений приложения нет.
- CodeGraph возвращал текущий исходник. Repowise был старым (9f3876d); index-only update выполнен без модельной генерации, однако MCP продолжил возвращать старые метаданные. Его оценки не считаются подтверждением текущего состояния.

Поиск/фильтрация только по представителю группы, полный раскрытый состав и приоритет выгодных явно закреплены в group-card-metrics и существующих E2E. Не объявлять это багами и не менять без отдельного решения. «Сейчас не выгодно» при отсутствии цены — спорная формулировка; причины выгодности не расширяются в этом change, чтобы не придумывать контракт.

## План и проверка

Порядок: поведение/доступность → панель сбора → каталог/выбор → детали/формы → визуальные эталоны и интеграционная проверка. Подробности, критерии и тесты — в proposal/design/specs/tasks change. Сохраняются шрифты, тема и установленный shadcn; без новых зависимостей, API и миграций.

Baseline существующего mock E2E: **41/41 passed (3.9m)** через временную конфигурацию `/tmp/pw-ui-audit.config.ts`, результаты в `/tmp/pw-ui-audit-test-results`. Первый запуск не стартовал из-за cwd временного config (`/tmp/package.json`); cwd исправлен, повтор прошёл. Повторяется предупреждение HydrateFallback, падений нет. `openspec validate improve-desktop-ui-usability --strict` и проверка whitespace прошли. Lint/unit/build/native smoke на стадии планирования не запускались.

Следующее действие: представить план и снимки пользователю и получить явное одобрение реализации. Вторая приёмка и финальные коммиты реализации остаются обязательными.
