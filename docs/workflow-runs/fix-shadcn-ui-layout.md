# Исправление геометрии UI после shadcn

Дата: 2026-10-21. Стадия: план подготовлен, явное согласование реализации ожидается.

Пользователь вызвал $vibe-flow и перечислил семь проблем: высота панели обновления,
выравнивание тегов/кнопки, скругления, уведомление выгодных предложений,
плашка исключения за границей строки, мелкие цены/наличие, отступ над фото плитки.

Change: openspec/changes/fix-shadcn-ui-layout. Proposal, design, spec delta и tasks
подготовлены по текущим исходникам. Код приложения не изменён.
План сохраняет серые группы и отступы по 8 px, новый Select и бизнес-логику.
Целевые значения: цены 14 px, наличие 13 px, отступ над фото 8 px.
Фиксированные 84 px строки заменяются минимальной высотой и ростом по метаданным.

CodeGraph использован для навигации; Repowise get_why не нашёл управляющих ADR,
индекс был позади HEAD и обновлён до текущей версии; часть генерируемых страниц
осталась stale по cascade budget, поэтому выводы сверены с текущими исходниками.
Источники подтверждают проблемы layout формы/уведомления/строк и мелкий Badge;
точная причина геометрии панели и охват скруглений проверяются в baseline.

Проверки реализации ещё не запускались; следующим шагом получить согласование
плана и затем применить change. Перед завершением нужна отдельная приёмка
по vibe-flow. Старый change migrate-ui-to-shadcn остаётся без изменения статуса.
