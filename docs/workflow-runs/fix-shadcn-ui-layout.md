Снимки: `/tmp/price-watch-layout-before/` при 1024×768 и 1440×900.
Наблюдения: панель running 81.28 px; кнопка тегов смещена вниз на ~30 px;

Уведомление содержало соседние текст/ссылку без layout, у фото не было

Скрипт baseline не дождался повторного уведомления при второй ширине:
повторные те же цены штатно не дают нового уведомления; отдельная
детерминированная проверка пяти предложений добавлена в E2E реализации.

## Реализация

- ActiveCollectionPanel: естественная высота, gap/padding, несжимаемые
  header/footer, ограничение viewport и scroll длинного содержимого.
- CardTagsEditor: общая строка Input/Button, отдельные label/description/error,
  связанный aria-describedby; подсказка/ошибка не меняют выравнивание.
- ToggleGroup: селекторы data-orientation, передача orientation примитиву,
  наружные скругления и ровные внутренние стыки.
- AppShell: уведомление с gap и отдельными ссылкой/именованным закрытием,
  оформление Alert/Button без старых неиспользуемых CSS deal-notice.
- Строки каталога растут по метаданным, содержат внутренние отступы;
  плашка не вылезает вниз, длинное название ограничено своей ячейкой.
  Превью сохраняет скругления. Цены 14 px, наличие 13 px в списке/истории.
  Размеры Badge плиток сохранены через контекстное применение стилей.
- В плитке сверху 8 px; фото остаётся 190 px с object-fit:contain.
