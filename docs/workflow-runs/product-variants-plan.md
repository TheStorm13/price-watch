## Запрос и согласование

Исходный запрос — редактирование карточки через панель создания с фиксированными площадкой и артикулом. Пользователь расширил его: хранить все SKU WB/AliExpress, независимо собирать цены каждого, выбирать главный для списков, показывать все истории разными цветами. Новый план и ADR 0011 согласованы сообщением «Да, приступай», затем пользователь попросил продолжить. `edit-card-fields` помечен SUPERSEDED.

## Реализованный план

- Товар → варианты → независимые наблюдения; `primary_variant_id` для каталога, групп и выгодных предложений.
- Forward-only миграция 0018 сохраняет старые ID вариантов, историю и снимки; preflight останавливает объединение при конфликтах общих настроек.
- Discovery WB/Ali внутри выбранного товара, точная цена каждого SKU, одна браузерная сессия, пакетное добавление целей, отдельные ошибки/повторы без повторения успешных SKU.
- API вариантов/фильтра истории, transfer v3, согласованные CLI add/list; числовой Ozon JSON-режим без БД.
- Общая панель изменения, таблица вариантов с поиском/главным, цветные линии и переключатели видимости, отдельный вариант таблицы измерений.
