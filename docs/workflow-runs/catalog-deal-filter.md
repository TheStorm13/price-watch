# Фильтр выгодности каталога

## План и согласование

Пользователь утвердил план 2026-11-05: заменить чекбокс на Select с пунктами
«Все», «Выгодные», «Не выгодные». Сохранить критерий выгодности карточек и
представителей групп. «Не выгодные» — точное дополнение к «Выгодные», включая
объекты без данных и с отключённым участием. Сохранить сочетание с остальными
фильтрами, выбор в URL и сброс к «Все». Изменение локальное, без OpenSpec,
изменения API, миграций и доступа к пользовательским данным.

## Реализация

Обновлены CardsPage, useCatalogModel и matchesItem; удалены стили чекбокса.
Параметр URL: deals=deals / deals=non_deals; отсутствие — все. Старый deals=1
больше не включает фильтр. Обновлены существующие unit/E2E тесты, добавлены
проверки дополнения, перезагрузки, поиска, сброса и групп с выгодным участником.
