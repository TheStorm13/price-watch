# Результат: коннектор Яндекс Маркета

Принято пользователем 2026-11-10: «задачу можешь закрывать».

## Решённая задача

Добавлен сбор Яндекс Маркета через авторизованный Chrome-профиль Price Watch
для desktop/API/worker и `main.py collect`. Удалены исключения pending-коннектора.
Ввод точного артикула обнаруживает все объявленные витриной варианты;
введённый артикул остаётся главным. Каждый SKU имеет собственную цену,
наличие, изображение и историю. Начальный сбор получает все цены, последующий
учитывает выбор tracking и новые варианты; повторные значения дедуплицируются.

## Принятые решения

- Цена — цена с картой Яндекса минус один лучший применимый промокод для одной
  единицы товара. Несколько кодов не складываются. При отсутствии цены по карте
  допускается проверенная обычная цена. Деньги рассчитываются через Decimal с
  ROUND_HALF_UP до двух знаков. Snapshot содержит основание расчёта и выбранный
  код; verification=calculated. Неизвестные условия и неподтверждённые абсолютные
  скидки исключаются с диагностикой.
- Browser-native fetch в общей вкладке сохраняет авторизацию профиля. Потеря
  входа не превращается в успешный снимок гостевой цены. Конечные retries,
  общий cooldown/recovery и индивидуальная отмена используют существующий пул.
- Обход SKU выполняется конкурентными волнами, до 100 HTTP-запросов одновременно.
  Задачи точных SKU и явных групп вариантов объединяются в пределах сеанса.
  Оборванный HTML повторяется на уровне запроса, включая HTTP 200.
- Внешний артикул проверяется отдельно от внутреннего marketSku. Явные варианты
  jumpListShort могут иметь разные productId; обычные HTML-контролы проверяются
  по parent product. Это сохраняет выбранный пользователем товар и полноту SKU.
- Неполный обход сохраняет подтверждённые данные с диагностикой и не удаляет
  прежние варианты. Frozen retry не расширяет persisted targets.
- Миграция 0022 добавляет unique index владения SKU Маркета; существующие
  конфликты останавливают миграцию без удаления данных. Add/import/discovery
  используют owner checks и advisory lock. Ценовые данные остаются в JSONB.
- CDN avatars.mds.yandex.net включён в существующий ограниченный allowlist fake
  DNS для миниатюр; проверки HTTPS, адресов и redirects сохранены.

## Проверка

До приёмки выполнены connector/collection/API/CLI/shared-browser регрессии,
PostgreSQL integration на отдельной disposable UTF8 БД, frontend lint,
unit и demo E2E. Числовой Ozon без DATABASE_URL и оба CLI imports проверены.
Demo E2E не подтверждает live backend.

После последних исправлений: 64 parser/discovery/transport/thumbnail/browser/Ozon
теста и 4 PostgreSQL integration-теста прошли. Проверены 100/101 admission,
coalescing, отмена pending-запросов, guest rejection, retry оборванного HTML,
начальные 10 SKU с разными productId, главный артикул и history dedup.

Live через авторизованный профиль: семейство 5355099814 собрано полностью
(64 SKU); цена исходного SKU 2663.10 RUB = 2959 минус CLOTH11 10%.
После исправлений семейство 6019174271 собрано 10/10, исходная цена
3058.20 RUB = 3398 минус HOME11 10%. Контрольный замер без запуска Chrome:
3.739 с против 13.554 с последовательного обхода; это не SLA.
Реальный ThumbnailService скачал фото и создал PNG 136×136 в отдельном
временном каталоге. Пользовательская БД и корзина в тестах не изменялись.
