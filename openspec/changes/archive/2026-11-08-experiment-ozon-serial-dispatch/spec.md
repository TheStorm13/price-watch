# Результат: асинхронный Ozon без планового лимита частоты, N=8

Принято пользователем 2026-11-08: «Все ок» после передачи реализации
`31f6a1dfe3c69fbb495af0ac31a5cc437f35d16b`. Задача завершена.

Ozon использует асинхронный браузерный JSON-сбор с фиксированным пределом восемь
одновременных product/modal-запросов и HTTP-повторов, без планового лимита стартов.
Общий сборщик допускает восемь попыток карточек Ozon; WB и AliExpress сохраняют
свои транспорты и общий пул пяти карточек. Внешняя пауза повтора освобождает слот.
Политика применяется к queued API/worker, прямому collect и числовому CLI без БД.
Сохраняются Retry-After/cooldown, таймауты, конечные повторы, независимая отмена,
одно согласованное восстановление страницы и проверка ответа. Миграций данных нет.

N=8 выбран пользователем после сравнения фиксированных N, не объявлен оптимумом.
Явная числовая частота оставлена для воспроизведения контрольных экспериментов;
обычный сбор не возвращается автоматически к прежним 5 стартам/с. Живые сравнения
использовали существующий профиль Chrome Price Watch, без сброса cookies/сессии.

Проверки реализации: 104 теста, без ошибок, 7 пропущены без disposable PostgreSQL;
барьерные тесты подтверждают перекрытие восьми запросов, ожидание девятого и
смешанный пул восьми Ozon плюс пяти остальных. Проверены cooldown, recovery,
отмена, lease loss, повторы и raw/numeric режим. Compileall, оба CLI --help без
DATABASE_URL, git diff --check и строгая валидация OpenSpec прошли. Индексы и
структурные страницы CodeGraph/Repowise обновлены на коммит реализации; model
page generation отключён. Repowise risk-запросы возвращали устаревший снимок и
не использовались как доказательство текущего риска.

Живые результаты на одинаковых 40 SKU:

- A/B/C/C/B/A: 240/240 успешно; среднее A (5,5/с) 7,577 с, B (1,5/с) 8,438 с,
  C (1,без плановой частоты) 7,107 с. [Метрики](measurements.json).
- C/D/D/C: 160/160 успешно, HTTP 200 без повторов/429/recovery. Среднее C 5,920 с,
  D (5,без плановой частоты) 1,424 с, ускорение 4,16 раза. [Метрики](measurements-cd.json).
- N5/8/12: первые десять пакетов 400/400 успешно; среднее успешного пакета
  N5 1,491 с (3), N8 1,069 с (3), N12 0,805 с (4). Последние два пакета N8/N5
  дали 80 ошибок подготовки сессии до отправки запросов; лог сообщал о закрытом
  браузере/контексте, причина закрытия не установлена. Первый N5 пересекался
  с локальными тестами. [Полные метрики, включая ошибки](measurements-fixed-n.json).

Короткие серии на прогретых связанных SKU не доказывают длительную устойчивость.
Наличие полей и их счётчики проверялись отдельно от значений цен/содержимого;
равенство содержимого не утверждается. CPU/RSS приблизительны по выборкам группы
процессов Chrome. Первоначальный headless-отказ не смешивался с видимыми замерами.
Полный PostgreSQL/desktop live-сбор при внедрении не повторялся; пользовательская
БД не использовалась. Другие коннекторы и адаптивный N не входили во внедрение.
