# Средняя цена как середина диапазона

Принято пользователем 2026-11-09. Исправлено отображение средней, которое исключало последнее наблюдение и могло совпадать с минимумом при выросшей текущей цене.

Средняя теперь равна `(минимум + максимум) / 2`, включая последнее наблюдение. Каталог и выгода используют всю сохранённую историю основного варианта; статистика истории — запрошенный период выбранного варианта. Учитываются только доступные (`in_stock`) ненулевые в смысле non-null цены; цена 0 допустима. Повторы наблюдений не меняют результат. При единственной цене средняя равна ей, выгоды нет. Без валидных цен средняя отсутствует. `baselineDays` считает дни с валидными ценами всей используемой истории.

Единая формула используется в PostgreSQL и demo. Старая база предыдущих дневных средних удалена, чтобы показатель и выгода имели один согласованный смысл. Decimal-точность сохранена, включая 100.005; история не переписывалась, миграции не нужны.

Проверки: 126 frontend-тестов, 51 backend-тест (включая отдельную disposable PostgreSQL-базу), TypeScript и CLI suite из 7 тестов с одним пропуском. Проверены повторы, крайние цены, точность, фильтрация наличия, период, группы и выгода. OpenSpec validate и diff checks прошли. Проверки живой карточки пользователя и desktop E2E не проводились. Временный PostgreSQL остановлен.
