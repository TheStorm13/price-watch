## MODIFIED Requirements

### Requirement: Автоматический сбор безопасно использует профиль браузера
Автоматический сбор SHALL не запускать второй Chrome с тем же профилем одновременно с вручную открытым через приложение Chrome. Перед запуском worker приложение SHALL штатно закрыть управляемый ручной Chrome и дождаться освобождения профиля либо зафиксировать ошибку.

#### Scenario: Наступил срок при открытом ручном Chrome
- **WHEN** наступает срок автоматического сбора при открытом через приложение браузере
- **THEN** приложение штатно закрывает вручную открытый браузер до начала автоматического сбора либо фиксирует ошибку запуска сбора, если профиль не удалось освободить
