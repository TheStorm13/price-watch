## ADDED Requirements

### Requirement: Каталог отрисовывает ограниченное окно элементов
Список и сетка SHALL отрисовывать только окно видимых карточек, заголовков групп и ограниченный запас. При неизменном viewport число элементов DOM SHALL NOT расти пропорционально размеру каталога или одной раскрытой группы. Прокрутка SHALL обеспечивать доступ ко всем результатам без изменения правил фильтрации и сортировки.

#### Scenario: Большая раскрытая группа
- **WHEN** пользователь раскрывает группу из 5000 карточек и прокручивает её до конца
- **THEN** доступны первая и последняя карточки, а DOM содержит только ограниченное окно участников

#### Scenario: Сетка после изменения ширины
- **WHEN** пользователь меняет ширину окна и число колонок сетки
- **THEN** карточки располагаются без наложения, пропуска или повторения и остаются доступны прокруткой

### Requirement: Ограничение DOM сохраняет выбор и навигацию
UI SHALL сохранять выбор карточек вне видимого окна, массовые действия, доступную навигацию клавиатурой и контекст возврата из деталей. Удаление элемента из окна SHALL NOT терять активный фокус или привязанный к нему открытый диалог.

#### Scenario: Выбранная карточка ушла за экран
- **WHEN** пользователь выбирает карточку, прокручивает каталог и выполняет массовое действие
- **THEN** действие включает выбранную карточку и корректно сохраняет неуспешные элементы выбранными

#### Scenario: Возврат из деталей
- **WHEN** пользователь открывает карточку из середины большого каталога и возвращается
- **THEN** восстанавливаются поиск, фильтры, вид и позиция просмотра соответствующей карточки

#### Scenario: Клавиатура и открытое меню
- **WHEN** пользователь переходит клавиатурой к следующей карточке или открывает меню действий и прокручивает страницу
- **THEN** целевой элемент остаётся доступен, фокус не исчезает, меню или диалог сохраняет корректного владельца
