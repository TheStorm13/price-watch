# Task: Ускорить колесико мыши в приложении

## Goal and acceptance criteria

Вертикальное колесико мыши прокручивает вдвое дальше за одинаковое число шагов. Нативная прокрутка WebKit сохраняется, включая вложенные области и границы. Тачпад, горизонтальная прокрутка и сочетания с модификаторами не ускоряются. Изменение ограничено Linux desktop, данных и серверных контрактов не касается.

## Current system and evidence

`frontend/src-tauri/src/webview_settings.rs` настраивает WebKit из `lib.rs` при создании главного окна. GTK3 уже входит в зависимости Tauri. DOM-перехват с ручным scrollBy заставил бы приложение самостоятельно выбирать вложенный контейнер и мог бы ухудшить нативную асинхронную прокрутку.

## Agreed solution

На GTK scroll-event определить вертикальное колесико по источнику Mouse (либо дискретное Up/Down без известного источника). Передать два экземпляра события через штатную GTK-диспетчеризацию с защитой от рекурсии и поглотить исходное событие. Тачпад, горизонтальные движения и Ctrl/Shift/Alt/Super/Meta оставить штатными. Подключить уже используемый gtk 0.18.2 напрямую, новых пакетов нет.

Авторизация: пользователь запросил повышение чувствительности; после сообщения о начальном коэффициенте ×2 пользователь сказал «Продолжи». Реализация ×2 входит в этот согласованный объем. Финальная приемка еще не получена.

## Implementation and verification plan

- [x] Подключить ускорение нативного колесика и описать поведение в руководстве desktop.
- [x] Проверить форматирование, Rust-компиляцию и фактическую доставку событий в WebKit на временной странице без пользовательских данных.
- [ ] Закоммитить изменение, обновить индексы и собрать устанавливаемый пакет.

## Execution state

Реализация готова. cargo check --offline, cargo fmt --check и git diff --check прошли. Временный Rust/GTK/WebKit стенд /tmp/pw-wheel-smoke.rs подключал production-функцию: одинаковое дискретное событие прокручивало страницу на 102 px без ускорения и 204 px с ним. Дополнительная проверка доставки показала два события для smooth Mouse и одно для Shift. Физический тачпад и вложенные контейнеры отдельно не проверялись; фильтры и нативная маршрутизация проверены по исходникам. FPS-прогоны не повторялись. Repowise live diff подтверждает текущий HEAD; предупреждение о сложности соответствует явным фильтрам входных событий. Версии зависимостей не изменены, lockfile добавляет только прямую связь gtk; полный набор серверных/E2E тестов не нужен.

Следующий шаг — commit, обновление индексов и пакет. Финальная приемка ожидается.
