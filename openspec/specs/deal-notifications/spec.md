# deal-notifications Specification

## Purpose

Определяет надёжную обработку уведомлений о выгодной цене в интерфейсе при
временных ошибках получения каталога и повторных обновлениях состояния запуска.

## Requirements

### Requirement: Ошибка загрузки не считается успешной обработкой уведомления
UI SHALL фиксировать обработку completed или completed_with_errors запуска только после успешного получения и обработки свежего каталога. Ошибка запроса SHALL оставлять работу ожидающей повтора с ограниченной частотой. Закрытие панели SHALL NOT отменять эту работу.

#### Scenario: Временная ошибка API
- **WHEN** первый запрос после завершения запуска завершился ошибкой, а последующий успешен
- **THEN** запуск не помечен обработанным после ошибки, а подходящая выгодная цена учитывается после успешного запроса

#### Scenario: Панель автоматически скрылась
- **WHEN** панель завершённого запуска скрылась до успешного повторного запроса
- **THEN** обработка уведомления продолжается независимо от видимости панели

### Requirement: Повтор обработки не дублирует уведомление
UI SHALL сохранять результат успешной обработки и сравнение ранее уведомлённых цен согласованно. Повторная доставка того же состояния запуска, повторный рендер или восстановление интерфейса SHALL NOT повторно создавать уже успешно обработанное уведомление.

#### Scenario: Повторное состояние completed
- **WHEN** данные уже успешно обработанного запуска повторно получены после рендера или открытия UI
- **THEN** новое уведомление для того же результата не создаётся

### Requirement: Правила отбора выгодной цены сохраняются
UI SHALL учитывать только актуальные выгодные предложения, чья последняя точка связана с обрабатываемым запуском и чья цена отличается от ранее уведомлённой. Failed-запуски SHALL NOT создавать уведомление об успешном сборе. Обработка SHALL NOT обещать восстановление исчезнувших исторических выгодных предложений.

#### Scenario: Цена прежняя или предложение исчезло
- **WHEN** полученный актуальный каталог не содержит новой подходящей выгодной цены для ожидающего запуска
- **THEN** обработка завершается без нового уведомления

#### Scenario: Перезапуск интерфейса после ошибки
- **WHEN** UI перезапущен с ожидающей обработкой, а API снова доступен
- **THEN** повтор использует актуальный каталог и сохранённую историю уведомлённых цен
